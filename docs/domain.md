# 林下设施面积闸门领域约定

项目面向集体林权改革与林下产业协作场景，管理森林康养木屋等项目获得权属凭证后的生产服务设施占用林地行为：乡镇支持项目落地，但占用面积必须严格压在宗地许可边界之内。

## 核心对象

- **宗地许可（Parcel）**：权属凭证对应的宗地，登记许可占用总面积（平方米）与现场核验容差。
- **项目（Project）**：落在宗地上的企业项目，可分阶段（期号）报建。
- **测绘图斑（Survey / Version）**：测绘批次下的图斑版本，携带测绘精度。新版本产生后自动成为当前版本；在途方案引用旧版本即被阻断，须按新版本重报。
- **分期方案（Plan）**：一期方案包含一处或多处设施图斑；方案生命周期为 已提交 →（首人放行）→ 已批准/已驳回/已撤回。撤回或驳回后，同一项目同一期号可以新编号声明前版重报。
- **共用设施**：跨项目共用的步道等作为一条独立方案登记并声明共用项目，面积只计一次。
- **现场核验与整改（Verification / Rectification）**：实测图斑与批准图斑比对面积偏差与越界部分，容差内通过；超差进入整改，复测合格且按实测面积重算宗地闸门后才能闭环。

## 闸门规则（任一不满足即阻断）

1. **累计面积**：宗地累计占用 = 所有生效（已批准）方案图斑面积之和；放行任一方案前计算 累计+本期 ≤ 许可面积。被驳回、已撤回的方案不占面积。
2. **空间冲突**：新方案图斑不得与任何生效批准图斑重叠；联合审查中在途方案两两核对。
3. **版本时效**：决定只能采用测绘批次的当前图斑版本。
4. **双审批人**：两名不同审批人都放行才形成批准；每次放行都按当时状态重新核算闸门（第一人放行期间不占面积，等待期间边界变化则第二人放行仍被阻断）。
5. **历史不可覆盖**：所有状态变化以只追加事件记录，已批方案永久保留其采用的图斑版本快照与面积，测绘换版不改变历史批准。

## 串行裁决

企业分阶段报建时，各期不能只看自己的图纸。联合审查按提交顺序串行模拟裁决：每放行一期立即占用剩余空间，后续期次按更新后的累计值判断；共用设施作为独立方案参与串行队列，不重复计面。

## 可追溯性

业务记录区分来源、发生时间与当前有效版本，所有对外结果都能追溯到采用的数据版本（`/events` 可查看完整事件流，当前状态由事件流归约得到）。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放。
