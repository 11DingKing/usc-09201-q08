# 林下设施面积闸门领域约定

项目面向集体林权改革与林下产业协作场景，业务记录需要区分来源、发生时间与当前有效版本。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放，所有对外结果都应能够追溯到采用的数据版本。

## 核心台账

- **宗地许可（Parcel）**：一宗地有林地权属凭证与许可占用面积上限 `allowedArea`，所有设施占用按宗地累计。
- **项目（Project）**：一个企业项目落在宗地上；同一宗地允许多个项目（如康养木屋与林下研学），共用设施跨项目去重。
- **测绘图斑版本（SurveyVersion）**：每次测绘形成不可变版本，包含若干图斑（矩形几何 + 面积）。版本可被新图纸取代（`superseded`，仅提示）或作废（`invalidated`，阻断待决审批）。
- **分期方案（Plan）**：企业分阶段报建，提交时**冻结**所采用的测绘版本与图斑面积；状态机为 `submitted → approved / rejected / withdrawn → rectification → approved`。

## 闸门规则（任何批准承诺前必须先计算）

1. **空间冲突阻断**：方案图斑与同宗地上已批准或其他待决方案图斑内相交即阻断；边界相接不视为重叠；同一 `sharedKey` 的共用物理设施不算冲突。
2. **累计面积阻断**：`已批准面积 + 其他待决方案面积 + 本方案面积 ≤ 许可面积`。待决方案计入累计，因此两名审批人连续/同时放行超额组合时任何一票都无法落下。
3. **分期累计**：闸门始终按宗地全局累计评估，不允许各阶段只看本阶段图纸。
4. **共用设施去重**：相同 `sharedKey`（或完全相同几何）的图斑全局只计一次，归属优先级为已批准 > 待决 > 本方案。
5. **版本冻结**：每次审批决定保存评估快照（采用的测绘版本、许可面积、冲突与累计结果）；批准后测绘版本即锁定，新图纸不得取代或作废，**历史批准不被覆盖**。
6. **撤回重报**：未批准方案可撤回，撤回后立即退出累计与冲突计算；可使用新图斑版本重报。已批准方案不得撤回。
7. **双岗审批**：须两名不同审批人各自放行（同一审批人不得重复投票），任一驳回即驳回；每次放行都重新执行闸门检查。

## 现场核验与整改闭环

- 已批准（含整改中）方案接受现场核验；实测几何与批准图纸不一致或出现未批设施，核验判失败并转入整改。
- 整改单 `open → closed`，闭环后方案恢复批准效力，占用面积维持批准值不变；整改中单次核验通过不能跳过闭环。
